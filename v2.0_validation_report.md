# ECHPlay v2.0 验证报告

验证日期：2026-06-17

版本目标：v2.0 完成 option / property / metadata 系统，让配置、统计和媒体元信息具备统一入口。

============================================================
一、完成内容
============================================================

1. 补齐 option category：format、codec、sws、player。
2. 新增 long option 快照 `getLongOptionsSnapshot()`。
3. 新增 String option 快照 `getStringOptionsSnapshot()`。
4. 新增 option 支持判断 `isOptionSupported(int category, String name)`。
5. 新增 ijkplayer 风格 property 常量。
6. 新增 `getPropertyLong(int property, long defaultValue)`。
7. 新增 `getPropertyFloat(int property, float defaultValue)`。
8. 新增 `ECHPlayer.MediaMeta`。
9. 新增 `getMediaMeta()`。
10. 新增 `getVideoDecoder()` 和 `getAudioDecoder()`。
11. `IECHMediaPlayer` 同步暴露 v2.0 新 API。
12. Demo prepare 成功后会输出 MediaMeta、property 和 option 快照摘要。

============================================================
二、已支持 property
============================================================

Long property：

1. `PROP_INT64_SELECTED_VIDEO_STREAM`
2. `PROP_INT64_SELECTED_AUDIO_STREAM`
3. `PROP_INT64_SELECTED_TIMEDTEXT_STREAM`
4. `PROP_INT64_VIDEO_DECODER`
5. `PROP_INT64_AUDIO_DECODER`
6. `PROP_INT64_VIDEO_CACHED_PACKETS`
7. `PROP_INT64_AUDIO_CACHED_PACKETS`
8. `PROP_INT64_BIT_RATE`
9. `PROP_INT64_TCP_SPEED`
10. `PROP_INT64_TRAFFIC_STATISTIC_BYTE_COUNT`

Float property：

1. `PROP_FLOAT_VIDEO_DECODE_FRAMES_PER_SECOND`
2. `PROP_FLOAT_VIDEO_OUTPUT_FRAMES_PER_SECOND`
3. `PROP_FLOAT_PLAYBACK_RATE`
4. `PROP_FLOAT_DROP_FRAME_RATE`

============================================================
三、暂未实现 property
============================================================

以下属性保留常量和入口，但 v2.0 会返回 defaultValue 或清晰默认值：

1. cache duration：等待 v2.6 缓存系统。
2. cache bytes：等待 v2.6 缓存系统。
3. async statistic buffer：等待 v2.6 缓存系统。
4. latest seek load duration：等待 v2.2 / v2.6 进一步统计。
5. playback rate：v2.0 固定返回 1.0，真实倍速放到 v2.4。
